# 平台使用指南

## 学习中心

- 报名成功后，在学习中心「我的班次」中查看所有在读与已完成的班次。
- 班次内按课程模块组织学习内容，每个模块包含若干课次。
- 课次类型包括直播、面授与录播视频；直播和面授课次有具体的开课时间。

## 学习进度查看

- 在学习中心可查看班次学习进度，包括四个维度：
  - 考勤：出勤次数 / 总课次数，缺勤次数。
  - 视频：完成视频数 / 总视频数，累计观看时长。
  - 作业：提交次数 / 总作业数，已批改次数。
  - 考试：参加场次 / 总场次，缺考场次。
- 考试分数明细（每场考试的得分）可在班次的考试列表中查看。

## 视频学习

- 录播视频支持断点续播，下次进入自动跳转到上次观看位置。
- 视频按章节切片，可通过章节列表快速定位。
- 视频观看进度达到 100% 记为完成。

## 作业与考试

- 作业在课次下布置，有截止时间；截止前可提交，逾期未提交记为过期未提交。
- 作业提交后由教师批改，批改完成可查看分数与反馈。
- 考试有作答窗口（开始与截止时间）与时长限制；截止后未进入的记为缺考。

## 订单与支付

- 我的订单中可查看订单状态（待支付 / 已支付 / 已完成 / 已取消 / 部分退款 / 已退款）、金额与支付时间。
- 待支付订单可以取消；已支付订单如需退回请发起退款申请。
- 一个订单可包含多个报名明细（多门课程或多期班次）。

## 智能客服与人工工单

- 智能客服支持：订单状态查询、学习进度查询、退款申请、工单提交，以及课程与政策咨询。
- 智能客服无法处理的问题可提交工单，类型包括：
  - 售后咨询：学习问题、资料需求等售后支持；
  - 投诉反馈：对课程或服务的投诉；
  - 退费申请：与退款申请关联的催促与跟进。
- 提交工单后可在工单列表查看处理进度与客服回复；工单处理完成可进行满意度评价。

## 会话与历史

- 智能客服会话历史自动保存，可随时回溯历史消息。
- 服务重启后，未完成的任务流程可以从上次的步骤继续。
