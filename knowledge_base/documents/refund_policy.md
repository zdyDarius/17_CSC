# 退款政策

## 退款适用范围

已支付或已完结状态的订单明细可以发起退款申请。以下情况不可发起退款：

- 待支付订单：无需申请退款，可直接取消订单。
- 已取消订单：订单已关闭，无退款必要。
- 同一订单明细存在待审批或已通过的退款申请时，不能重复发起，需等待当前申请处理完成。

## 退款类型

退款申请必须选择以下四种类型之一：

| 类型 | 编码 | 适用场景 |
| --- | --- | --- |
| 个人原因 | personal_reason | 个人时间安排、计划变动等自身原因 |
| 课程不满意 | course_unsatisfied | 对课程内容、教学质量不满意 |
| 时间冲突 | schedule_conflict | 与工作、学习时间冲突无法参加 |
| 重复购买 | duplicate_purchase | 重复下单购买了相同课程 |

## 退款金额

- 退款金额为所选订单明细的实际支付金额（全额退款）。
- 订单使用优惠券等优惠的，优惠抵扣部分不退还现金，按实付金额退款。
- 一个订单包含多个报名明细时，退款只针对所选明细，不影响其他明细的学习。

## 退款流程

1. 提供订单号，选择要退款的报名明细。
2. 填写退款原因并选择退款类型。
3. 确认退款金额（系统自动计算，展示明细全额）。
4. 提交申请，获得退款编号（RF 开头），状态为待审批。
5. 审核结果通过消息通知；审核通过后按原支付渠道退回。

## 处理时限说明

退款申请提交后进入人工审核队列，具体审核时长以客服实际处理为准，平台不承诺固定时限。如申请长时间未处理，可提交退款类工单由人工客服跟进催促。

## 温馨提示

- 退款申请提交前请仔细核对订单明细与金额，确认页展示的信息即最终退款依据。
- 退款审核通过后，对应报名关系会终止（已退费），课程学习权限将同步关闭。
- 如对退款结果有异议，可通过工单（投诉反馈类型）继续跟进。
